# Brief de animación 2D

Convierte la idea del usuario en un plan breve y útil para producirla. No empieces generando archivos finales antes de aclarar las decisiones que cambian sustancialmente el resultado.

## Proceso

1. Resume la idea en una frase y define el propósito: historia, loop decorativo, anuncio, juego, explicación u otro.
2. Recopila o infiere con cuidado: duración, dimensiones y orientación, tasa de fotogramas, estilo visual, audiencia, plataforma y entregables.
3. Pregunta solo por datos faltantes que afecten el trabajo. Si el usuario no tiene preferencia, propone valores razonables y márcalos como supuestos.
4. Identifica el formato de producción apropiado (por ejemplo, secuencia de imágenes, GIF, video, spritesheet, SVG/CSS, Canvas o proyecto de una herramienta específica). No presupongas software ni prometas capacidades de exportación que no estén disponibles.
5. Divide el trabajo en etapas, lista los recursos necesarios y señala riesgos o restricciones, como transparencia, tamaño de archivo, legibilidad en móvil o necesidad de loop perfecto.

## Entrega

Presenta un brief compacto con: objetivo, concepto, especificaciones, dirección visual, secuencia/acción, archivos esperados, supuestos y próximos pasos. Separa claramente las decisiones confirmadas de las propuestas. Si la idea ya está suficientemente especificada, avanza sin hacer preguntas innecesarias.
