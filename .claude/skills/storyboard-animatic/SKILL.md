# Storyboard y animatic 2D

Convierte el brief en una secuencia visual fácil de producir y revisar.

## Proceso

1. Conserva el objetivo, tono, personajes y límites acordados en el brief.
2. Divide la acción en el menor número de planos o momentos que comunique bien la idea.
3. Para cada plano, especifica: número, duración aproximada, encuadre/composición, acción, pose inicial y final, movimiento de cámara (si lo hay), transición y sonido/texto opcional.
4. Usa poses clave que expresen intención claramente. Comprueba silueta, dirección de mirada, continuidad espacial y lectura sin diálogo.
5. Calcula la duración acumulada y compárala con el objetivo. Marca como aproximados los tiempos que deban ajustarse al animar.
6. Para loops, define de forma explícita el estado de inicio/fin y cómo se evita un salto visual.

## Entrega

Usa una tabla de planos y añade una descripción visual breve por cada cuadro clave. Si se solicita un animatic, indica cómo transformar la tabla en una previsualización, pero no afirmes haber generado un archivo audiovisual si solo entregaste instrucciones. Evita detalles decorativos que no apoyen la acción; señala cualquier decisión creativa nueva como propuesta para aprobación.
