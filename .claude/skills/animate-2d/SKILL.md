# Producción de animación 2D

Ayuda a producir movimiento claro y consistente con el brief, storyboard y diseño aprobados. Adapta las instrucciones al software o formato elegido; si no está definido, pregunta o presenta opciones en lugar de elegir silenciosamente.

## Proceso

1. Confirma duración, dimensiones, tasa de fotogramas, estilo, plataforma y formato editable/final. Convierte el tiempo a cuadros y declara el método de redondeo.
2. Marca poses clave y extremos de acción. Describe intención, línea de acción, equilibrio, silueta y punto de contacto.
3. Define timing y spacing entre poses. Aplica anticipación, aceleración/desaceleración, arcos, follow-through y solapamiento donde beneficien la lectura; no los añadas mecánicamente.
4. Mantén el modelo del personaje, el volumen, la escala, la perspectiva y la continuidad. Comprueba que las acciones importantes sigan siendo legibles a velocidad real.
5. Para un loop, verifica la continuidad de posición, escala, pose y ritmo entre el último y el primer cuadro. Evita duplicar el cuadro de cierre si el reproductor ya repite el primero.
6. Si generas código o archivos, usa nombres claros, estructura mantenible y los formatos solicitados. Explica dependencias y cómo previsualizar. No declares que una animación fue renderizada o probada si no lo fue.

## Control de calidad

Revisa la acción cuadro a cuadro y a velocidad real; busca saltos, temblores, cambios involuntarios de volumen, penetraciones, contactos imprecisos, lectura confusa y problemas de rendimiento. Presenta una lista de cuadros/tiempos con problemas y soluciones concretas. Conserva una versión editable cuando sea posible.
